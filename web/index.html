Wii Homebrew

Dev Wii Game

An open-source custom homebrew game for Nintendo Wii

Download & Installation

Download the compressed release package below. Unzip the file and place the dev folder directly onto your SD card's /apps/ directory.

Download dev.zip (v1.0.0) Includes compiled boot.dol and meta.xml

SD Card Directory Layout

SD Card (root)/
└── apps/
    └── dev/
        ├── boot.dol
        ├── meta.xml
        └── icon.png

Built with devkitPPC & libogc | Launch via Homebrew Channel
